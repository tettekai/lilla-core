# スキル

スキルは、使い回す指示プロンプトに名前を付けて保存しておき、`!skill <スキル名>` で
呼び出す機能です。呼び出すと、そのターンの **最新の user メッセージ** としてプロンプトが
展開され、通常の会話と同じ流れで LLM に渡ります（システムプロンプトには入りません）。

今は明示的なコマンド呼び出しだけに対応しています。LLM がスキルの説明を見て自分で
使い分ける仕組みは今後の拡張予定です。

## 登録する

スキルは観測用ダッシュボード（[観測用ダッシュボード](dashboard.md)）の **Skills** 画面で
管理します。一覧・追加・編集・削除・有効 / 無効の切り替えができます。

| 項目 | 内容 |
|------|------|
| 名前 | 呼び出しに使う名前（必須） |
| 説明 | 一覧に出す説明（任意。ダッシュボードの一覧と `!skill` の一覧に表示される。将来、LLM がスキルを選ぶ手がかりにする予定） |
| 本文 | 展開するプロンプト（必須） |
| 有効 | 無効にしたスキルは呼び出せません（追加直後は有効） |

保存先は MongoDB の `skills` コレクションです（`name` にユニークインデックス）。

### 名前の規則

- 使える文字は半角英数字・アンダースコア（`_`）・ハイフン（`-`）のみで、最大 64 文字です。
  空白は含められません（コマンドの引数を空白で区切るため）
- 大文字小文字は区別しません。保存時も呼び出し時も小文字に正規化して照合します。
  `Review` と `review` を別々に登録することはできず、`!skill Review` は `review` を呼びます
- 規則に合わない名前や、既にある名前と重なる名前は、追加・編集の時点でエラーになります

## 呼び出す

```
!skill <スキル名> [追加指示]
```

スキルの本文は、ユーザー自身の発言ではなく **システムからの動作指示** として LLM に読まれる
よう、開始行・前置き文・終了行のラッパーで囲んで展開します。スキル名の後ろに書いた文字列
（最初の空白以降）は追加指示として、前後の空白を除いたうえで、ラッパーの後ろに `追加指示: `
のラベル付きで続けます（複数行なら 1 行目にだけラベルが付きます）。たとえば本文が
「次の文章を校正して」のスキル `proofread` を `!skill proofread 今日は良い天気でした。` で
呼ぶと、LLM には次の user メッセージが渡ります。

```text
[システム指示: スキル「proofread」]
以下はユーザーの発言ではなく、システムからの動作指示です。この指示に従って応答してください。

次の文章を校正して
[/システム指示]

追加指示: 今日は良い天気でした。
```

追加指示が無い（空・空白だけの）ときは、`追加指示:` の行を付けずラッパーだけを渡します。

```text
[システム指示: スキル「proofread」]
以下はユーザーの発言ではなく、システムからの動作指示です。この指示に従って応答してください。

次の文章を校正して
[/システム指示]
```

ラッパーの文言とラベルは `ui.locale` に合わせて切り替わります（`en` なら
`[System instruction: skill "proofread"]` / `[/System instruction]` /
`Additional instructions: `）。

- 展開した内容は、そのまま会話履歴に user メッセージとして残ります。スキルを後から
  編集・削除しても、過去の履歴は保存した時点の内容のまま読まれます
- 以前の形式（`---SKILL: <スキル名>---` 〜 `---END_SKILL---` の区切りマーカー）で保存済みの
  履歴は移行せず、そのまま残ります
- 返答の送り方（入力中表示・分割送信・返答の履歴保存）は通常の会話と同じです。同じ
  チャンネルで返答中の会話があれば、通常の会話と同じくそれを打ち切ってから始めます
- メンションなしで呼び出せます（他の `!` コマンドと同じ）
- 存在しない・無効なスキルを指定すると、LLM を呼ばずに元のチャンネルへエラーを返します
- オーナー以外からの `!skill` は、他のコマンドと同じく承認フローの対象です
  （承認チャンネルで承認されると実行されます）

### スキルの一覧を見る

スキル名を付けずに `!skill` だけを送ると（空白だけの引数も同じ）、LLM を呼ばずに、
呼び出せるスキルの一覧を同じチャンネルへ返します。

```text
利用できるスキル:
- `proofread`: 文章を校正する
- `review`
呼び出し方: `!skill <スキル名> [追加指示]`
```

- 載るのは **有効なスキルだけ** で、スキル名の昇順に並びます。無効なスキルは呼び出せない
  ため載りません
- 説明があれば `名前: 説明`、無ければ名前だけを表示します。説明の改行は空白に置き換えて
  1 行にします（長い説明も切り詰めません）
- 有効なスキルが 1 件も無いときは、一覧の代わりに「利用できるスキルはありません」と、
  ダッシュボードの Skills 画面から登録できる旨を返します
- 一覧が Discord の 1 メッセージに収まらないときは、行の区切りで複数のメッセージに分けて
  続けて送ります
- オーナー以外からの一覧表示も承認フローの対象で、承認されると元のチャンネルへ一覧を返します
