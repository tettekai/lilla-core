# プロンプトのテンプレート（Jinja2）

運用者が書くプロンプトの本文は、使うたびに Jinja2 のテンプレートとして展開してから LLM へ渡します。
展開の処理は 1 つ（`lilla_core.services.prompt_template.render_template()`）で、どのプロンプトも
同じ規則で展開されます。

## 展開するもの・しないもの

展開するのは、運用者が書くプロンプトだけです。

| プロンプト | 渡す変数 |
|------------|----------|
| `prompt.system` / `prompt.conversation` / `prompt.discord` | `current_hour` |
| LLM プロバイダーの `prompt`（[プロバイダーごとの追記](llm-provider-prompt.md)） | `current_hour` |
| `llm_expert` の `prompt`（[ツール契約](tools.md)） | `current_hour` |
| `task_scheduled_llm` の `prompt`（[スケジュール実行](scheduled-llm.md)） | `current_hour` |
| 拡張の `client_prompt_providers()` が返した本文 | `current_hour` |
| スキルの本文（`!skill` と `llm_load_skill`。[スキル](skills.md)） | `current_hour` |
| 拡張のプロンプト（[デフォルトと上書き](extension-prompt.md)） | `current_hour`・`settings` |

次のものはデータなので展開しません（中に `{{` があってもそのまま渡します）。

- 会話履歴・ユーザーメモ・部屋のノート・ツールの結果・外部エージェントの返信
- `!skill` の追加指示（利用者の入力）、スキルの名前と説明（スキルの一覧）
- コードに書いてある固定の文言

## 共通の変数

| 変数 | 中身 |
|------|------|
| `current_hour` | 今の日時を `ui.timezone`（[タイムゾーン](timezone.md)）で `YYYY-MM-DD HH:xx` にした文字列（例: `2026-11-14 20:xx`）。曜日は付けません |

分を伏せて時までにしているのは、システムプロンプトの中身が 1 時間ごとにしか変わらないようにして、
LLM 側のプロンプトのキャッシュを効かせるためです（会話履歴の現在時刻と同じ考え方です）。
`task_scheduled_llm` では、基準の時刻はそのタスクの実行時刻です。

```markdown
いまは {{ current_hour }} です。今日のうちに済ませることがあれば教えてください。
```

## 書き方の規則

- 使えるのは Jinja2 の通常の構文（`{{ 名前 }}`・`{% if %}`・`{% for %}`・フィルターなど）です。
  展開はサンドボックスで行い、テンプレートから Python の属性やモジュールへは届きません。
  HTML ではないため自動エスケープはしません
- 未定義の名前（綴り間違いや、廃止した `{{now}}` など）は空文字にせず失敗にします
- 本文の末尾の改行は残します（記法を含まない本文は展開しても変わりません）
- `{{` / `{%` / `{#` を文字として書きたいときは、`{% raw %}…{% endraw %}` で囲みます

## 失敗したとき

展開に失敗した場合（構文エラー・未定義の名前など）は、どのプロンプトかを含む WARNING ログを出し、
**展開前の本文をそのまま** 使います。会話やタスクは止めません。

スキルだけは、ダッシュボードの Skills 画面で保存するときに今の時刻で試しに展開し、
展開できなければ 400 で保存しません（試しの展開で確かめられるのは通る分岐だけです）。
拡張のプロンプトの上書きの保存時の検査は [拡張のデフォルトプロンプトと上書き](extension-prompt.md) を
参照してください。ファイルから読むプロンプトには保存時の検査がないため、書き換えたあとは
ログの WARNING を確かめてください。

## `{{now}}` からの移行

以前の `task_scheduled_llm` は、プロンプト中の `{{now}}` を `YYYY-MM-DD HH:MM` の実行時刻へ
置き換えていました。この置き換えは無くなり、`{{now}}` は未定義の名前として展開に失敗します
（WARNING を出して `{{now}}` が残ったまま LLM へ渡ります）。

`{{now}}` は `{{ current_hour }}` に書き換えてください。分までは入らなくなります。
既存のプロンプトに `{{` / `{%` / `{#` が文字として含まれていないかも確かめ、含まれていれば
`{% raw %}` で囲むか書き方を変えてください。

```sh
grep -rnE '\{\{|\{%|\{#' "$CONFIG_ROOT/prompt" "$CONFIG_ROOT/tools"
```
